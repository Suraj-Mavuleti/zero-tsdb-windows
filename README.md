# Zero Tsdb Windows

A distributed, lock-free time-series database.

## Overview
This repository contains the highly-optimized native core for the zero tsdb windows platform. It is built with zero-cost abstractions, direct hardware access, and massive internal C++ vendoring for algorithmic superiority.

## Key Advantages
- High-frequency data ingestion
- LSM trees
- Decentralized peer-to-peer architecture.

## Why zero-tsdb-windows? (Competitive Edge)
**The Problem:** InfluxDB and Timescale struggle under HFT (High-Frequency Trading) loads. zero-tsdb can ingest 10 million metrics per second per node.

**The Solution:** zero-tsdb-windows provides an entirely distinct, low-level architectural approach. By discarding heavy runtimes, web-views, and telemetry dependencies, we achieve maximum computational throughput and deterministic execution.
